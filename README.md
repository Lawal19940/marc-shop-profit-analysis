# Marc Shop - Profit Analysis 
 
Real client project for small shop in Benin. Analyzed 3 products profit. 
 
## Key Insights 
- **Top Product: iPhone 13 case - 15,000 profit** 
- Power bank: 12,000 profit 
- Screen protector: 12,000 profit 
- Total: 39,000 profit
